# keyconf launch film

A 36-second, 1920×1080 Hyperframes film. Revision two uses a continuous Three.js keyboard, camera moves, animated color changes and assembly, real component UI, recorded switch sounds, and a real Monkeytype guest run.

## Preview and render

Requires Node.js 22 or newer, Chrome with WebGL2, and FFmpeg. Hyperframes can install its pinned Chrome build. Hardware GPU rendering is recommended for the supersampled 3D scene.

```sh
npm ci
npm run build:stage
npm run check
npm run snapshot
npx hyperframes preview --background --port 3333
npm run render
```

Open `http://localhost:3333/#project/keyconf-launch`. The finished export is `renders/keyconf-launch.mp4`; the checked-in release is `launch.mp4`. `index.html` owns the continuous 3D canvas, three overlay compositions, footage timing and audio envelopes. The editable camera, keycap geometry, materials, palette transitions and key travel are in `scripts/cinematic-stage.mjs`.

The renderer draws at 2880×1620 inside the 1920×1080 composition. It uses deterministic ambient occlusion, contact shadows, a reflection environment and camera-dependent depth of field. Hyperframes' `hf-seek` completion barrier waits for model/font initialization and GPU completion. No wall-clock animation drives the film.

## What is real

- The keyboard study uses the app's original `keyboard-60.glb` and 60% layout, with new cap geometry, legends, switch housings and a perforated plate for close-up animation. It is an original representative product illustration, not manufacturer CAD.
- Forest Line, Blush and Midnight are demonstrated as colorways on that study. They do not imply identical vendor layouts or geometry.
- The selected switch row and Gateron Oil King card are native-resolution screenshots of actual app controls. `scripts/capture-detail.mjs` reproduces the capture against the local app.
- The Monkeytype widget is cropped from a real guest-test recording, at its original speed. Source timestamps are retained in `assets/audio/typing-cues.json`; the film does not invent typing results.
- Gateron Ink Black press/release recordings come from tplai/kbsim under MIT. That listening reference is separate from the Oil King component shown earlier. Level and modest stereo position change; pitch does not. MP3 source recordings do not become lossless or exact assembly measurements by mixing into PCM.
- The original 120 BPM score and transition sounds are generated by `scripts/score-cinematic.py`. Its cue file also drives visible key travel. The listening sequence substantially ducks the score.

## Audio and export

Install Python `numpy` and `soundfile` to regenerate the stems with `npm run score`, then run `npm run master:audio`. The master script reads actual stem timing and volume envelopes from `index.html`. It applies constant gain without compression, limiting, EQ or pitch changes. The included 24-bit, 48 kHz stereo master measures −19.08 LUFS integrated and −1.20 dBTP; true-peak headroom limits the gain before the nominal −18 LUFS target.

Hyperframes 0.8.29's streaming MP4 path previously failed its duration check by two frames. The render script uses the official PNG-sequence export, verifies all 1,080 numbered frames, then encodes H.264 with 320 kbps stereo AAC through FFmpeg. The final duration is 36 seconds. The render script then decodes the output and checks frame count, dimensions, stream duration, audio format, true peak and unintended black intervals. Run `npm run verify:render` to repeat those checks. `npm run render -- --encode-only` reuses an already complete frame sequence.

Raw captures, proof renders, dependency caches and diagnostics are excluded from Git. For a standalone source inspection, serve this directory on port 3344 and run `node scripts/inspect-cinematic.mjs`; it captures source poses and checks that forward and reverse seeks produce identical pixels. Full composition checks and snapshots remain necessary to review text, footage and layering.
